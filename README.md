# Orchestra

> **WIP:** source coming after cleaning up and ensuring no secret leaks.

Orchestra is an operator workbench for orchestrating projects, workflows, tasks, sessions, agents, and human-in-the-loop review.

This GitHub repository is currently acting as the public landing/microsite while the main source repository is being cleaned up for public release.

## Current status

- Public GitHub Pages landing page is available here: https://berdon.github.io/orchestra/
- Source code is not yet published in this GitHub repository
- Public source will be added after cleanup and verification work is complete

## What Orchestra is about

- Customizable workflows and lanes
- Multi-repo project support with worktree-aware execution
- Persistent supervisor/agent orchestration
- Rich permissions and review controls
- Mobile and chat-driven orchestration support
- Secure secret-sharing support across tasks
